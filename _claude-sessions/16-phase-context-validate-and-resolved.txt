  **Recommendation:** It is the only option where the file never passes through

  **Recommendation:** The phase literally describes the cycle "rascunho →

  - TD-07 and TD-13 still get exact states: the cleanup job queries `draft` rows

  publication kept in its own Phase 04 field, A provides the same separation and

  state to `uploading` and require API docs explaining that "rascunho" means

  "rascunho" in the *publication* sense, and a processed but unpublished video

  field/values without reusing `draft`.
  **Libraries:** —
